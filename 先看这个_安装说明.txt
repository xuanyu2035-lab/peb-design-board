PEB 设计板 2.2 安装说明
======================

【电脑：现在就能用】
1. 把整个文件夹放到电脑上任意位置（不要只拿 index.html 一个文件也行，但整个文件夹更好）。
2. 双击 index.html，用 Edge 或 Chrome 打开。
3. 断网也能用。内容会自动存在这台电脑的浏览器里。

【iPad：要先放到网上一次】
iPad 不能直接打开电脑里的网页文件，要先把这个文件夹放到一个网址上（GitHub 免费）。
这一步由 Claude 帮你做，你只需要建一个 GitHub 账号。
有了网址以后：Safari 打开网址 → 点"分享" → "添加到主屏幕"。之后断网也能用。

【两边互传】
文件 → 一键导出全部（或"只导出稿件文件"）→ 存到云端硬盘
另一台设备：文件 → 打开稿件文件 → 从云端硬盘选这个文件
一次只在一台设备上改。打开比现在旧的文件时，程序会提醒你。

【交给 Claude】
把"一键导出全部"得到的 .zip 发给 Claude 就行。
Claude 做的设计也是一个文件：文件 → 加入另一份稿件。紫色虚线的就是 Claude 的提议，点"采纳"就变成你的。

【常用操作】
- 加东西：选"框/按键/点"，在同一个位置连点两下。点一下只选中，可以拖动。
- 框的大小：上方"宽""高"各选 整、1/2 … 1/7，表示把所在的框或页面等分（会扣掉间距）。选中一个框再点，它就改成这个大小。
- 拉大小：拖右边改宽，拖下边改高，拖右下角等比例缩放。
- 间距：选中一个框，旁边有"间距"（预定 0~48）和"自定义"。拖动时，框和框、框和边的距离接近这个数就会自动吸过去，并显示粉色的距离标记。
- 复制：Ctrl+C 复制，Ctrl+V 粘贴到鼠标位置，Ctrl+D 或旁边的"复制一份"放到右边（隔一个间距）。右键也有这些。
- 在框里面编辑：长按一个框。按"退出框"出来。
- 放大缩小：滚轮，或两根手指。移动画面：按住页面外面的空白拖。
- 每一栏右边的"锁"：锁住这一栏，框里的东西一起锁。
- 逻辑说明：文字区上方切到"逻辑说明"，用文字写这一页的逻辑，点标签插入【键1】【框2】。
- 组件：上方"组件"后面的 ＋ 新建，单独设计一个功能栏；"零件 → 我的组件"放进页面。

【和 Claude 一起设计某一页】
1. 文件 → 导出这一页给 Claude（空白页就是模板），把 zip 发给 Claude。
2. Claude 交回一个 .json：里面有这一页的图、右边每一栏的名字和解释、这一页的逻辑说明。
3. 文件 → 加入 Claude 的设计 → 选"作为新的一页"（或替换原来那一页）。紫色虚线的是 Claude 的，满意就"采纳"。
